# Licensing and attribution

OpenIPERA separates licenses by **type of material**, not by where a file happens to be hosted.

| Material | Terms |
| --- | --- |
| Original software, scripts, and executable source code | [Apache License 2.0](https://github.com/openipera/openipera-architecture/blob/main/LICENSE) |
| Original architecture documentation, specifications, diagrams, and website prose | [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://github.com/openipera/openipera-architecture/blob/main/LICENSE-DOCUMENTATION.md) |
| OpenIPERA name, woven-eye logos, and project-specific visual branding | [Reserved project branding](https://github.com/openipera/openipera-architecture/blob/main/BRANDING.md) |

Documentation reuse requires appropriate attribution, a license link, and an indication of changes. The documentation license does not grant permission to imply official OpenIPERA endorsement.

Software may be reused under Apache 2.0 subject to its terms, including preserving applicable notices.

**Third-party material** and contributions whose owners have not authorized these grants are not automatically relicensed. Consult individual notices where present.

For authoritative terms, see the [repository license files](https://github.com/openipera/openipera-architecture).
